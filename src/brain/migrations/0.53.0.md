The owner's Canvas, when Demiurge syncs it, now reaches the session context as a Canvas block beside the Calendar: what is due in the next seven days and not handed in, anything missing, grades from the last three days and announcements from the last two. The morning briefing names schoolwork from it when it is there, and the watch routine raises a new grade, announcement or missing assignment once. Owners without Canvas see nothing new.

1. Run `brain install-skills` to install the updated morning and watch instructions.
2. Run `brain validate`; fix what it names.
3. Run `brain migrate-done`.
