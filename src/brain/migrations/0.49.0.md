Background workers now run both regular and daily handed-off tasks. Daily tasks enter the worker due list at noon in the owner's local time, once per day. The continue routines and their monitor checks are retired.

1. Run `brain schedule list`. If the vault has no declared schedule yet, run `brain schedule import` first to preserve its runtime routines.
2. Remove `continue` and `continue-daily` if present with `brain schedule remove continue` and `brain schedule remove continue-daily`. Already absent routines need no action. Keep every other routine as it is; the runtime reconciles the removals.
3. Run `brain install-skills` to install the updated continue and recall instructions.
4. `brain validate`; fix what it names, then `brain migrate-done`.
