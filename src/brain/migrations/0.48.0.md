Responsibilities now have stable ids and schedule links; routines can declare that they need the owner's computer.

1. Run `brain install-skills`.
2. Read `brain state --json` and `brain schedule list --json`. A responsibility's id is its hub's `records`, else its skill without the configured prefix, else its title: lowercase, replace non-alphanumerics with hyphens, trim, and limit to 63 characters. For each responsibility hub whose routine is not linked by name or skill, set `brain schedule set <routine> --responsibility <id>` only when exactly one routine plausibly belongs to it (its `skills` includes the hub's skill). Keep existing explicit assignments. Leave ambiguous or absent matches unchanged; do not invent routines or change their timing.
3. Run `brain validate`, fix what it names, then `brain migrate-done`.
