A task can rest until the owner's computer is reachable. `--resume computer` keeps it out of both continue paces until the runtime calls `brain continue --wake computer`. The state snapshot exposes these open tasks in `waitingOnComputer`.

1. Run `brain install-skills` to install the updated continue and recall instructions: rest on the computer when only delivery there remains, report once, and try an available next step before answering a status question.
2. `brain validate`; fix what it names, then `brain migrate-done`.

No task data rewrite or global configuration change is needed. Detecting the computer's return and calling wake are the runtime's responsibility.
