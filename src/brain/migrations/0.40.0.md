Tasks now converge on their Delivers line. Work names where a made thing lives; every background handoff also needs Delivers. The engine supplies direction-review context and applies the harness reviewer's verdict after four chunks by default.

1. Run `brain install-skills` to install the updated continue and recall instructions. Continue starts with Delivers, proves delivery before producing volume, closes a finished task and rests when the remaining step is outside its reach.
2. Check `brain continue --due --json`. Handed-off tasks missing Delivers are held and get one task-sourced Needs you question. Do not invent a finish line for existing tasks; use the owner's answer or their already recorded instruction.
3. `brain validate`; fix what it names, then `brain migrate-done`.

No task data rewrite or global configuration change is needed. Review calls are the runtime's responsibility; the engine never calls a model itself.
