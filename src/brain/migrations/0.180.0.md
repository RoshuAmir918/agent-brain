The evening now starts from a pre-run script, `evening-signal.sh`, which prints everything it decides (quiet tasks, quiet and surplus asks, open asks, Needs you problems, stuck loops, what was answered today) as one JSON, and nothing when there is nothing to decide; then the run is skipped.

1. Run `brain install-skills` and `brain install-scripts`.
2. Read `brain schedule list --json`. If an `evening` routine exists without a script, run `brain schedule set evening --script evening-signal.sh`, keeping its cron, prompt and every other field. One that already has a script stays as it is.
3. Run `bash $AGENT_HOME/scripts/evening-signal.sh` once; it exits 0 and prints JSON or nothing.

Verify `brain schedule check`. Run `brain migrate-done` to record 0.180.0.
