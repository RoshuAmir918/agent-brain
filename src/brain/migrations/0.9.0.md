Routine session transcripts leave the vault.

The nightly export now writes conversations to `Conversations/Sessions/` and everything else, the agent's own cron and evaluation sessions plus every JSONL shard, to this profile's `$HERMES_HOME/records/sessions/`. Each agent on a shared machine has its own Hermes home, so each keeps its own records, and the vault holds only memory. `brain digest` and `brain attribute` read the records folder by default; `brain paths records` prints it.

Do this without the owner, it needs no decisions:

1. `mkdir -p "$(brain paths records)/sessions"` and `cd "$VAULT_REPO"`.
2. Copy `Conversations/Sessions/jsonl/` into that folder, then `git rm -r -q` it.
3. Copy every `Conversations/Sessions/cron_*.md` into that folder, then `git rm -q` them. Do the same for evaluation sessions: files whose name contains `retrieval-check`, `retrieval-test`, `evaluation-fixture` or `rc-` followed by two digits.
4. Leave `Conversations/Sessions/*.md` for real conversations where they are; leave `Conversations/Digests/` alone.
5. In your Hermes README (or wherever you documented the export), say where routine sessions live now.
6. `brain validate`, commit `chore(brain): move routine session records out of the vault`, then `brain migrate-done`.
