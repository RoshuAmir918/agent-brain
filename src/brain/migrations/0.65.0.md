1. Run `brain install-skills`.
2. In a personal vault, run `brain portrait seed --account all --json`. If no owner account has synced mail or calendar files, skip the seed. Otherwise load the newly installed seed skill and run it once for all owner accounts. Keep existing portrait ids, corrections and refusals; add or update rather than duplicate. File only the owner's own facts in Tellable. The reveal is one confirm; a close-friends proposal, when needed, is a separate ask. Silence never creates a group or widens access. Enterprise vaults skip this step and make no content changes.
3. Run `brain validate`; fix what it names.
4. Run `brain migrate-done`.
