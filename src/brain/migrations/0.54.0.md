A newly connected account now gets a registry row and one question to the owner about what they want from it, and the improve and explore routines build on new connections and on Canvas deadlines. This also covers Canvas schools connected before this version.

1. Run `brain install-skills` to install the updated recall, improve and explore instructions.
2. List `$AGENT_HOME/channels/`. For each folder named for a host (no `@`) that holds a `courses.md`, a synced Canvas school, check your channel registry (`Channels.md` in your agent folder) for a live row naming that host. If there is none, run `demiurge canvas accounts` and add the row as the recall skill describes: `owner`, the host as identity, `demiurge canvas` and `$AGENT_HOME/channels/<host>/` as reach, read as courses, assignments, grades and announcements, write as submit, post and message only if `demiurge canvas accounts` says you may act there and otherwise none, granted as the owner in Demiurge with today's date, status `live`. Add a dated line to `Channels/History.md` beside it: registered by the 0.54.0 migration, connect question not yet asked.
3. Run `brain validate`; fix what it names.
4. Run `brain migrate-done`.
