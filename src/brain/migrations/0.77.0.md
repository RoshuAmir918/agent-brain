The default schedule named its two script routines `<prefix>export.sh` and `<prefix>refresh.sh` (`brain-export.sh` and `brain-refresh.sh` with the default prefix), but the engine installs `export-sessions.sh` and `refresh.sh`. A vault whose schedule came from those defaults has run neither session export nor the hourly context refresh.

1. Run `brain schedule list --json`. For each routine whose `script` is `<prefix>export.sh`, run `brain schedule set <name> --script export-sessions.sh`. For each routine whose `script` is `<prefix>refresh.sh`, run `brain schedule set <name> --script refresh.sh`. Leave every other routine alone.
2. Run `brain schedule check`; fix what it names.
3. Run `brain migrate-done`.
