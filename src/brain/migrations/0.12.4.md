The owner's timezone, and three Memory Spec principles.

`brain.toml` gained `timezone`, default `America/Los_Angeles`. The export script's "yesterday", digest day boundaries and the dates in `brain health` and `brain audit` all use it. A profile whose owner is in another zone than the host was archiving the wrong day.

Do this without the owner:

1. If {human_name}'s timezone is not America/Los_Angeles, add `timezone = "<IANA zone>"` to `brain.toml`, then `brain timezone` to read it back. The next export archives the right day; the digests already written for the wrong day are left alone.
2. Make sure `{agent_dir}/Memory Spec.md` ends with principles 13, 14 and 15, copying any that are missing from the starter vault's Memory Spec in `agent-brain-template`: 13 a routine owns three places; 14 standing work has three homes; 15 the owner's goals are a lens, not a script.
3. Commit `chore(brain): record timezone and spec principles`, push, then `brain migrate-done`.
