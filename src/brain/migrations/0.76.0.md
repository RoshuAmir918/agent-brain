A task's Next, Status, Blockers, Ask and Why are read by your owner in their app, so they are written for your owner. `brain validate` now names an open task whose field is written for a maintainer instead: the word "maintainer", code, a command, a file path or a raw thread id.

1. Run `brain install-skills` to install the current recall and continue instructions.
2. Run `brain validate`. For each line naming a task field "written for a maintainer", rewrite that field with `brain task T-nnn set --<field> "..."` so it says, in a sentence and plain words, what the situation means for your owner ("Waiting on the Slack connection to be fixed"; "Paused until the Mac Studio is set up"). Keep the technical detail: write it as a dated line in the note the task's evidence links (or a new note under the task's hub, linked with `--evidence`). Change nothing else about the task.
3. `brain validate` again until no field is named, then `brain migrate-done`.
