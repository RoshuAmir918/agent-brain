# The evening review posts nothing

The evening routine's Boundaries say "No messages", but its run was delivered to the owner's Home, so its account (counts, word limits) reached them as a message. New vaults schedule it with `deliver = "local"`; live vaults need the same.

1. Run `brain install-skills`.
2. Run `brain schedule list --json`. For each routine whose skills include `{prefix}evening` and whose `deliver` is not `local`, run `brain schedule set <name> --deliver local`. Leave every other routine alone.

Verify: `brain schedule check` reports no problems, and no routine with `{prefix}evening` delivers anywhere but `local`. Then run `brain migrate-done`.
