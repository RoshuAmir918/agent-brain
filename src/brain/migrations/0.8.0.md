Maintainers and the health report.

`brain health` now prints an operational report (stage runs, engine state, export coverage, counts) and the hourly refresh commits it to `{hermes_dir}/health.md`. `brain.toml` gained `maintainers`: platform ids of whoever keeps this brain running without owning it. A session from a maintainer gets the health report and the rules for what may be said to them.

With {human_name} present:

1. Run `brain health` and show {human_name} the output.
2. Ask whether anyone maintains this brain besides {human_name}: the person who set it up, or an agent that checks on it at night. With their yes, add those platform ids as `maintainers = [...]` in `brain.toml` and restart the gateway so the provider reads it.
3. Commit `chore(brain): record maintainers`, then `brain migrate-done`.
