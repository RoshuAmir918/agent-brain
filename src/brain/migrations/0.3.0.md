Install the automatic Hermes memory provider with the owner present.

1. From the vault repository, run `brain install-provider`. This copies the
   provider into `$HERMES_HOME/plugins/brain` without editing global config.
2. Set `memory.provider` to `brain` with
   `hermes config set memory.provider brain`.
3. Ask the owner for their platform user IDs; do not guess or use a display
   name. For Slack, this is the `U...` user ID. Add them to `brain.toml`:

   ```toml
   [brain]
   owner_user_ids = ["U_OWNER_ID"]
   ```

   Merge this key into the existing `[brain]` table. Include alternative IDs
   for the same owner where needed. CLI sessions are always owner sessions.
4. Restart the gateway. Verify by starting a session from a non-owner Slack
   account, or asking the agent what its provider block says. A known person
   should have a profile and disclosure rules; an unknown person must receive
   the stranger warning, not an owner identification. Confirm that the owner's
   own account receives only the owner identification.
5. Finish with `brain migrate-done`.
