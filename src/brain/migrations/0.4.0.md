Profiles split into Profile and History.

A person's `Profile.md` now holds only what is stable (identifiers, relationship, impression, what they care about, standing facts, disclosure notes) and stays under 300 words, because the memory provider puts it whole into every session with that person. Dated interactions, claims and requests live in `History.md` beside it, newest first.

Do this without the owner, it needs no decisions:

1. For every `{people_dir}/*/Profile.md` over 300 words, create `History.md` in the same folder with frontmatter `kind: log`, move every dated entry there (newest first, one line each: date, channel, what was said or asked, how it went), and leave each fact in the Profile as one sentence. End the Profile with a History link.
2. For profiles under 300 words, add the History link only; create the file when the first dated entry arrives.
3. Check `{people_dir}/Profile Template.md` has the Identifiers and History sections; if it was customised, merge them in.
4. Run `brain validate`, commit `people: split profiles into Profile and History`, then `brain migrate-done`.
