Library works can keep a summary at the top of their page, in the same kit as task views. `brain works view <slug>` reads JSON on stdin and saves it as the work's `view.json`. Living works and large collections keep it current in the same chunk that changes what it summarises; a one-off document needs none.

1. Run `brain install-skills` to install the updated continue, recall and setup instructions.
2. Run `brain validate`; fix what it names.
3. Run `brain migrate-done`.
