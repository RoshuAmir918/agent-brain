# Google and Canvas through `use`

Demiurge replaced the `demiurge mail`, `demiurge calendar` and `demiurge canvas` commands with the `use` tool: `use { connection: "google:<account>", action, input }` and `use { connection: "canvas:<school host>", action, input }`. `demiurge guide google` and `demiurge guide canvas` list the actions and their inputs. The synced files under `$AGENT_HOME/channels/` are unchanged.

1. Run `brain install-skills` so the recall skill teaches `use`.
2. In `{agent_dir}/Channels.md`, for every `owner` row whose reach names `demiurge mail`, `demiurge calendar` or `demiurge canvas`, replace that command with `use` and the connection (`google:<account>` or `canvas:<school host>`). Keep the files, read and write columns, grant and status as they are.
3. Search your vault's skills, routines and notes you wrote yourself for those three commands and change each to the matching `use` call.
4. Add one dated line to `{agent_dir}/Channels/History.md`: the Google and Canvas rows now reach their accounts through `use`.

Verify: no row in `Channels.md` and no routine in `schedule.toml` names `demiurge mail`, `demiurge calendar` or `demiurge canvas`. Then run `brain migrate-done`.
