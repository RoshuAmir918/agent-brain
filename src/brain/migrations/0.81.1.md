A hotel, rental or flight named under `experiences` in the tellable note told every friend allowed experiences where the owner was staying. Lodging and travel are now only whereabouts, and a reservation that has not yet passed is whereabouts too.

1. Run `brain install-skills`.
2. In a personal vault with a `Tellable.md` beside the owner's profile, look at each line under `## experiences`. Remove a line about lodging or travel (a hotel, suites, rental, flight, an Airbnb stay), keeping or adding the matching `## whereabouts` line with its dates. A reservation whose date is today or later moves to `## whereabouts`; one already passed stays, without its date. Add no new facts.
3. Run `brain validate`; fix what it names.
4. Run `brain migrate-done`.
