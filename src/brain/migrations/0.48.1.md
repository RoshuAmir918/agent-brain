Tasks now carry a view: data the owner sees above the task's thread and on its card, in the kit your recall skill describes. Views were only chosen at handoff, so the tasks you already have show none. Give each open task the view it should have had.

1. Run `brain install-skills` to install the current recall and continue instructions, then read the view part of your recall skill.
2. `brain state --json` lists your tasks with any view they keep. For each open task without one, decide whether its result has a shape: candidates being compared, items done of a total, gates to pass, stages it moves through, places, a schedule. A task whose result is a document, an answer or a decision has no view; skip it. So does setup or maintenance work with nothing the owner would look at.
3. For each task that has a shape, write its view with `brain task T-nnn view` (JSON on stdin, `{"pieces": [...]}`), from what the task and its evidence notes already hold. Do no new research, and never invent a number, a price or a state you have not recorded: a piece you cannot fill truthfully is left out. Each thing appears in one piece, counts match what they count, and any piece whose data you read somewhere says so in `from`. A refused view comes back with the kit printed; fix it and write it again.
4. `brain validate`; fix what it names, then `brain migrate-done`.
