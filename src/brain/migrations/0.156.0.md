Triggers retire. "When X, do Y" is now a `when` loop, which loads into every session under Holding, and a standing direction about a person lives in that person's profile, which loads whenever they or their intellect are in a session.

1. Run `brain install-skills`. Read `{agent_dir}/Triggers.md`. Leave the `## Fired` and `## Retired` sections alone.
2. For each row above them, decide what it is, from its `when`, `do` and status:
   - **Still to happen**, a date or a condition not yet met: `brain loops --add "<do, as one sentence>" --kind when --source "<its source note, without brackets>"`, with `--due YYYY-MM-DD` (or `"YYYY-MM-DD HH:MM"`) when `when` is a date, and `--if "<when, as a condition>"` when it is a condition, both when it is both. Add `--with <name>` when it waits on a person or intellect you know.
   - **A standing direction**, with no end ("never relay…", "always decline…", "keep this boundary until {human_name} changes it"): add it with its created date as a line under `## Working together` in the profile of the person it is about (create the section at the end when it is missing). When it is about {human_name}, the section is in `{human_profile}`. Merge it with a line that says the same.
   - **Done or moot**, already fired, fulfilled, retired, or its condition can no longer happen: nothing to carry.
3. Point what links to `[[…/Triggers]]` (START, SOUL, hubs) at `[[{vault}/{agent_dir}/Loops|Loops]]` instead, or drop the link where it no longer says anything true. Then move the file: `git mv "{agent_dir}/Triggers.md" "{agent_dir}/Triggers Archive.md"`, and set its frontmatter to `kind: log` and `tier: cold`. It is history now; nothing reads it.
4. Run `brain loops` and check that each carried row is there once. Then `brain validate`, fix what it names, `brain compile-context --write`, and `brain migrate-done`.
