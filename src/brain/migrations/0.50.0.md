The Library is kept by use: opening a work keeps it. The night asks once about your own unopened drafts at seven days; the backend retires drafts still unopened at fourteen days, and they remain restorable. Older listings without created and opened fields are left alone.

1. Run `brain install-skills` to install the updated recall instructions for answering a Library ask.
2. Run `brain validate`; fix what it names.
3. Run `brain migrate-done`.
