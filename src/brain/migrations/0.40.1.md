Needs you gets shorter clocks and one question per task. An ask with no task retires after 5 unanswered days (the evening decides it from 3), a confirm is taken as accepted after 5, and an ask whose source names a task carries that task (`task` in `brain needs-you --json`), is replaced by a newer ask for the same task, and settles with the task instead of lapsing.

1. Run `brain install-skills` to install the updated evening instructions.
2. `brain validate`; fix what it names, then `brain migrate-done`.
