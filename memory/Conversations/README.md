# Conversations

Dated evidence records. Two kinds live here:

- **Topical records** the agent writes after a conversation that changed something durable: `YYYY-MM-DD <title>.md`, with the owner's words quoted and dated, decisions separated from suggestions. These are what hubs cite.
- **Sessions and Digests**, written by the nightly export: `Sessions/` holds every Hermes session as exported, `Digests/<date>.md` holds one day of turns between the owner and the agent. Cold, never indexed; reached by `session_search` or grep.
