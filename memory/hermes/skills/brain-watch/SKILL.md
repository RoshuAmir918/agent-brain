# Watch guard

An hourly pass for deadlines, things needing Human today, and register accuracy. Not a memory path.

## Procedure
1. Read the last hour of the channels in `agent/Channels.md` and Agent's own mailbox; check later replies first.
2. Reconcile only important, actionable facts into the owning task: status, deadline, waiting-on, next step. A date-conditioned commitment becomes a commitment trigger. Durable but non-urgent facts get a dated line on the task with a `morning:` tag; Sleep 1 consolidates them.
3. Message Human only for something that needs them today. Overnight findings wait for 08:00. Flag ambiguity instead of inventing decisions.
4. Proactive outreach to anyone other than Human happens only if Human has approved it in writing, with a roster and pacing rules recorded under Standing state in `agent/Tasks.md`. With no such record, send nothing.

## Boundaries
Never edit hubs, profiles or CURRENT's active threads. Never copy message bodies. No disclosure of profile or private information, no commitments on Human's behalf, no spending.
