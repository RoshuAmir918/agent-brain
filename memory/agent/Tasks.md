# Current tasks

The register of work the owner has asked for. The latest evidence timestamp belongs to each task; this page's edit time is not progress evidence.

[[memory/START|START]] is the entry point. [[memory/CURRENT|CURRENT]] gives compact present context. Owning hubs hold project detail; this register holds execution status and next steps. Do not import historical suggestions as new commitments.

## Status and maintenance

Use stable IDs (`T-001`, `T-002`, ...); retain an ID when ownership, status or the next step changes. Statuses are **ready**, **in progress**, **blocked**, **waiting for owner**, **completed** or **cancelled**. A task is open until it has completion evidence or the owner cancels it; blocked and quiet are both open. The nightly script places each open task by activation: hot as a full entry under 150 words, warm as one line with the body in `Tasks Archive/T-nnn.md`, cold as archive only. Completed tasks go to `Tasks Archive/YYYY-MM.md` with their evidence link.

For every active task record: outcome, status, owner, source request, verified progress with a timestamp, next concrete step, blocker or needed decision, permitted scope and completion evidence.
